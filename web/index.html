SCAD AI IDE / LIBRARY MANAGEMENT

From discovery to your workspace.

SCAD AI IDE is an open-source VS Code extension for OpenSCAD development. SCAD Registry is its companion library metadata infrastructure, not a separate IDE or package installer. The IDE's Library Manager discovers indexed libraries, selects exact tags or snapshot commits, and restores project dependencies using declarations and lockfiles. Its shared versioned cache supports project-local mounts and project-scoped OPENSCADPATH.

THE MAIN PRODUCT

More than library management.

SCAD AI IDE brings the OpenSCAD toolchain, code editing, interactive 3D preview, visual parameter controls and evidence-based design review into VS Code. Supported native AI Agent hosts can access bounded CAD and environment services; no LLM is bundled. The IDE is currently a source-first development preview, not an official Marketplace release. Consult the main product website for current capabilities, requirements and limitations.

MACHINE-READABLE DATA

Commit-pinned library metadata.

SCAD AI IDE is the primary consumer of the versioned registry JSON, which is also available to other tools. Resolve exact GitHub or Codeberg source archives. The catalog lists curated libraries, not every OpenSCAD library. Each upstream project retains its own license.

Registry JSON API · Catalog and API guide

Discover

Read name, ID, description, license, repository and documentation URLs.

Resolve

Use versions and commit-pinned download URLs; latestVersion may be null. Do not infer the latest stable version from array order.

Check

Inspect sync.status and generatedAt. Metadata is not compatibility certification, dependency resolution or installation.
